### Zephyr

Working on **AI-generated image forensics** and **multimodal agents** — the part where a model's
answer has to come with evidence you can actually audit.

---

**[AIGC-Actor-Monitor](https://github.com/Zephyr-Feng/AIGC-Actor-Monitor)** — an Actor calls frozen
forensic tools and leaves an auditable evidence trail; an independent Monitor reviews attribution,
sufficiency and when to stop.
<br/><sub>Structured Actor → FaithBench → offline Monitor → online intervention</sub>

**[Senior-Talk](https://github.com/Zephyr-Feng/Senior-Talk)** — speech-based mental-health screening:
VAD, Whisper transcription, acoustic features, semantic evidence, and an MLLM review step that ends
in an evidence-citing report rather than a bare label.

**[Daily-Routine-System](https://github.com/Zephyr-Feng/Daily-Routine-System)** — a desktop schedule
manager that listens: voice input, speech recognition and an LLM assistant, built with C++ and Qt.
